# Image Convert Lite

ブラウザ内で完結する、軽量な画像変換アプリの MVP です。  
画像はサーバーにアップロードされず、すべてお使いの PC 上のブラウザで処理されます。

## 対応機能

- 多形式画像の選択・ドラッグ＆ドロップ（入力: JPG / JPEG / JPE / JFIF / PNG / WebP / BMP / AVIF / ICO）
- **フォルダ単位での一括読み込み**（サブフォルダ内の画像も対象）
- **読み込み上限**（500枚 / 25MB per file）
- 出力形式の選択（JPG / PNG / WebP）
- 画質設定（1〜100、JPG / WebP のみ）
- 横幅リサイズ（空欄なら元サイズ、指定時は縦横比を維持）
- 複数画像の一括変換
- **変換中の進捗表示**（軽量なバッチ更新）
- **変換の停止・再開**
- **変換完了時の結果表示**（成功 / スキップ / エラー件数と理由）
- **直前の変換結果の保持・表示**
- 変換設定が変わらない場合は再変換ボタンを無効化
- **出力ファイル名の重複回避**（ZIP 内でサブフォルダ構造を維持）
- 変換後画像の個別ダウンロード
- 複数画像の ZIP 一括ダウンロード
- 変換前後のファイル名・形式・サイズ・解像度の一覧表示

## 対応形式

| 種別 | 形式 |
|------|------|
| **入力** | JPG / JPEG / JPE / JFIF / PNG / WebP / BMP / AVIF / ICO |
| **出力** | JPG / PNG / WebP（AVIF 出力は未対応） |

- 入力判定は **MIME タイプ** と **拡張子** の両方で行います（`.jpe` / `.jfif` など MIME が空のファイルにも対応）
- 変換処理は Web Worker 経路を優先し、`createImageBitmap` → `OffscreenCanvas` → `convertToBlob` で実行します
- ICO は Chrome / Edge でデコード可能な単純なアイコンを対象とします（複雑なマルチサイズ ICO は環境により失敗する場合があります）

ターミナル操作に慣れていなくても、この順番どおりに進めればローカルで起動できます。

### よくあるエラーと対処法

#### エラー: `The term 'node' is not recognized...`

**原因候補**

- Node.js がまだインストールされていない
- インストール後にターミナルを開き直していない
- インストール時に PATH への追加が無効になっていた

**対処**

1. ステップ 2 の手順で Node.js LTS をインストールする
2. Cursor と PowerShell を完全に閉じて、再度開く
3. `node --version` で確認する

#### エラー: `The term 'npm' is not recognized...`

**原因候補**

- Node.js と一緒に入るはずの npm が PATH に通っていない
- Node.js のインストールが不完全

**対処**

1. Node.js を再インストールする（LTS 版）
2. ターミナルを開き直して `npm --version` を確認する

#### エラー: `ENOENT: no such file or directory` や `cd` で移動できない

**原因候補**

- プロジェクトフォルダのパスが間違っている
- フォルダ名やドライブ名が異なる

**対処**

1. エクスプローラーで `d:\My_app\Image Convert Lite` が存在するか確認する
2. パスが違う場合は、実際のフォルダパスに合わせて `cd` コマンドを修正する

#### エラー: `npm install` 中にネットワークエラー（`ETIMEDOUT` など）

**原因候補**

- インターネット接続の問題
- 社内ネットワークやプロキシの制限

**対処**

1. インターネット接続を確認する
2. 少し時間をおいて `npm install` を再実行する

#### エラー: `Port 5173 is already in use`

**原因候補**

- すでに別の開発サーバーが 5173 番ポートを使っている

**対処**

1. 以前起動した `npm run dev` を `Ctrl + C` で停止する
2. ターミナルに表示された別の URL（例: `http://localhost:5174/`）を使う

## 使い方

1. **画像を追加する**
   - 画面上部のエリアに画像またはフォルダをドラッグ＆ドロップする
   - 「画像ファイルを選択」で個別ファイルを選ぶ
   - 「フォルダを選択」でフォルダ内の画像をまとめて読み込む
   - **入力**: JPG / JPEG / JPE / JFIF / PNG / WebP / BMP / AVIF / ICO に対応（非画像ファイルは自動でスキップ）
   - 読み込み後、何枚追加されたかが画面上部に表示されます

2. **変換設定を行う**
   - **出力形式**: JPG / PNG / WebP から選択
   - **画質**: 1〜100（JPG / WebP のときのみ有効）
   - **横幅リサイズ**: ピクセル数を指定（空欄なら元のサイズのまま）

3. **一括変換を実行する**
   - 「一括変換」ボタンを押す
   - 一覧に変換前後の情報が表示されます
   - 変換後、設定と画像に変更がなければ「一括変換」ボタンは無効になります
   - 設定を変更するか、新しい画像を追加すると再度変換できます

4. **ダウンロードする**
   - 各行の「ダウンロード」で個別保存
   - 「ZIP でまとめてダウンロード」で複数ファイルを一括保存

5. **画像を削除・クリアする**
   - 各行の「削除」で個別削除
   - 「すべてクリア」で一覧をリセット

## フォルダ読み込みについて

### できること

- フォルダ内の対応画像（JPG / JPEG / JPE / JFIF / PNG / WebP / BMP / AVIF / ICO）をまとめて読み込み
- サブフォルダ内の画像も再帰的に読み込み（Chrome / Edge など）
- テキストファイルや PDF など、非画像ファイルは自動で無視

### ブラウザの制約・注意点

| 項目 | 内容 |
|------|------|
| フォルダ選択 | Chrome / Edge / Firefox など、モダンブラウザで利用可能 |
| フォルダのドラッグ＆ドロップ | Chrome / Edge で対応。Firefox ではフォルダ D&D が使えない場合があります |
| 読み込み件数の表示 | 読み込んだ画像枚数と、スキップした非画像ファイル数を表示 |
| ファイル名の表示 | フォルダ読み込み時は `フォルダ名/サブフォルダ/ファイル名` 形式で表示 |
| セキュリティ | ブラウザの制約により、フォルダ内のファイルパス情報は限定的です |

> **Firefox をお使いの場合**: 「フォルダを選択」ボタンからの読み込みは可能ですが、フォルダのドラッグ＆ドロップが使えない場合はボタンから選択してください。

## 一括変換ボタンの動作

- 初回変換前、未変換の画像がある場合、変換エラーがあった場合は「一括変換」が有効
- 一括変換完了後、出力形式・画質・横幅リサイズが前回と同じで、新しい画像も追加されていない場合は無効
- 設定を変更すると、再度「一括変換」が有効になります
- 新しい画像を追加すると、再度「一括変換」が有効になります
- 無効時はボタン付近に「設定または画像を変更すると再変換できます。」と表示されます
- 変換中は常に無効です

## 読み込み上限

安定性のため、以下の上限が設定されています。

| 項目 | 上限 |
|------|------|
| 1回に読み込める画像枚数 | **500枚** |
| 1ファイルあたりのサイズ | **25MB** |

### 上限を超えた場合の動作

- **25MBを超える画像** → 読み込まずスキップ（例: `「photo.jpg」: 25MBを超えるためスキップしました`）
- **500枚を超える画像** → 上限まで読み込み、残りはスキップ（例: `最大500枚を超えたため、15枚をスキップしました`）
- すでに一覧にある枚数も含めて、合計500枚までです
- 非画像ファイル（PDF やテキストなど）は従来どおり自動でスキップされます

ボタンの位置は変換中・完了後も固定で、スクロールせずに ZIP ダウンロードできます。

- ファイル・フォルダの追加
- 変換設定の変更
- 個別ダウンロード
- 画像の削除
- すべてクリア

### 変換の停止・再開

| 状態 | 主ボタン | 動作 |
|------|----------|------|
| 通常時 | 一括変換 | 全画像を変換 |
| 変換中 | **停止** | 現在の1枚が終わった時点で停止（エラー扱いにしない） |
| 停止後 | **再開** | 未変換の画像から続行（変換済みは再変換しない） |
| 停止後に設定変更 | 一括変換 | 設定変更時は再開ではなく再変換扱い |

- 停止後は「停止しました」と変換済み枚数を表示します
- 停止後も変換済み分の個別ダウンロード・ZIP ダウンロードが可能です
- 「すべてクリア」で画像一覧・変換結果・停止状態を初期化できます

## 変換速度について

### 変換処理の構成（Web Worker 正式採用候補）

画像の decode / draw / encode は **Web Worker を優先**して実行します。Worker 内では `createImageBitmap` → `OffscreenCanvas` → `convertToBlob` を使用し、メインスレッドの UI 描画や他タブの動画再生の影響を受けにくくしています。

| 経路 | 条件 | encode 方式 |
|------|------|-------------|
| **Worker（優先）** | `Worker` と `OffscreenCanvas` が利用可能 | OffscreenCanvas.convertToBlob |
| **メインスレッド（fallback）** | Worker 起動失敗・エラー時 | HTMLCanvasElement.toBlob |

変換時間診断パネルでは **process mode**（worker / main-thread / mixed）と **encode mode**（offscreen-canvas / html-canvas）を確認できます。

### UI 最適化の方針

変換処理本体に加え、**React の再描画回数**も削減しています。

| 項目 | 対策 |
|------|------|
| 画像ごとの state 更新 | 5枚ごとにまとめて更新（バッチ更新） |
| 進捗表示の更新 | 100ms 間隔にスロットル |
| 変換中の一覧更新 | 「変換中」ステータスの都度更新を廃止 |
| ファイル名正規化 | 変換時1回のみ（ダウンロード時に再処理しない） |
| 変換履歴 | 変換完了時に1回だけ保存 |

### 変換速度が遅い場合

- 一度に大量の画像（数百枚）を変換するとブラウザの負荷が高くなります
- 横幅リサイズを指定すると処理が軽くなることがあります
- 変換中は画像一覧の更新頻度を下げているため、進捗バーは滑らかでも一覧の状態更新は数枚おきになります
- **大量画像変換中に、同じブラウザで YouTube などの動画を再生すると、変換速度が低下する場合がありました**（メインスレッド encode 時）。**Web Worker 経路ではこの悪化が大幅に改善されることを確認済み**です
- **動画を別ブラウザで視聴すると回避できることがあります**
- **速度が戻らない場合は、ページを再読み込みして動画を停止した状態で変換するか、動画再生と変換処理を別々のブラウザで行ってください**
- 変換中に低速化を検知した場合は画面上部に警告が表示されます（最初の10枚の toBlob 平均を基準に、直近10枚が **3倍以上** かつ **1000ms以上** のときのみ。低スペック端末で最初から遅いだけの場合は警告しません）。変換を停止した後は「ZIPでまとめてダウンロード」から変換済み分のみ取得できます

### リソース診断（開発用）

画面下部の「リソース診断（開発用）」で、以下を確認できます。

| 項目 | 意味 |
|------|------|
| 画像数 | 読み込み済み画像の枚数 |
| 変換済み Blob 数 | メモリ上に保持している変換結果の数 |
| 作成済み / revoke 済み Object URL 数 | プレビュー用 URL の生成・解放回数 |
| 有効な Object URL 数 | 未解放の URL 数（画像数とおおむね一致するのが正常） |
| JS ヒープ使用量 | Chrome 等で `performance.memory` が使える場合のみ表示 |

YouTube 視聴後に変換が遅くなった場合、この表示で「有効な Object URL 数」や「変換済み Blob 数」が異常に増えていなければ、ブラウザ全体（GPU / メモリ）への負荷が原因の可能性が高いです。

### 変換時間診断（開発用）

画面下部の「変換時間診断（開発用）」で、各画像の **decode / draw / toBlob** 時間を計測します。

| 項目 | 内容 |
|------|------|
| 平均・最大時間 | decode（読み込み）、draw（描画）、toBlob（JPGエンコード） |
| 遅延警告 | いずれかが 2000ms 以上の場合、コンソールに表示 |
| 低速化判定 | baselineToBlobMs / currentToBlobMs / slowdownRatio（相対判定の診断用） |
| コピー | 通常時・YouTube後・再読み込み後の結果をコピーして比較可能 |

**切り分け手順：**

1. 通常変換 → 「この診断結果をコピー」
2. YouTube を10秒再生して停止 → 再変換 → コピー
3. ページ再読み込み → 再変換 → コピー
4. 3つの結果で **どのフェーズ（decode / draw / toBlob）が増えたか** を比較

推定ボトルネックが `toBlob` の場合は Canvas エンコード/GPU 枯渇、`decode` の場合は WebP デコード枯渇の可能性があります。

### 前回の変換結果（折りたたみ）

2回目以降の変換を行うと、1つ前の結果は「▶ 前回の変換結果」として折りたたみ表示されます。  
クリックすると日時・成功件数・スキップ件数・エラー件数・変換設定を確認できます。

### スキップ・エラーの詳細

- 読み込み時のスキップ理由 → 画面上部の黄色い警告メッセージ
- 変換エラーの詳細 → 画像一覧の各行、または画面上部のエラーメッセージ

### 変換履歴について

- アプリ内で変換のたびに履歴を保持します
- 最新の結果は操作バー左側に表示されます
- 「すべてクリア」を押すと、画像一覧と変換履歴がリセットされます

## 出力ファイル名の重複対策

同名ファイルが複数ある場合、上書きされないように自動で名前を付け替えます。

- 例: `sample.jpg` → `sample_2.jpg` → `sample_3.jpg`
- **フォルダ読み込み時**は、ZIP 内でサブフォルダ構造を維持します  
  - 例: `photos/2024/sample.jpg` → ZIP 内も `photos/2024/sample.jpg`
- サブフォルダが異なれば同名ファイルでも競合しません  
  - 例: `folderA/sample.jpg` と `folderB/sample.jpg` はそのまま別ファイルとして保存

## ダウンロード時のファイル名（日本語対応）

### 採用方式

| 処理 | 方式 |
|------|------|
| 個別ダウンロード | ブラウザ標準の `<a download>` + `Blob URL` を使用（UTF-8 ファイル名を維持） |
| ZIP 内のファイル名 | JSZip で UTF-8 ファイル名を設定（非 ASCII 文字を含む場合は ZIP の UTF-8 フラグを利用） |
| ファイル名の正規化 | Unicode NFC 正規化、パス区切りの統一、無効文字の除去 |

### 基本方針

- 元のファイル名に日本語が含まれる場合、**できるだけ元の名前を維持**します  
  - 例: `画像テスト.png` → `画像テスト.jpg`
- フォルダ読み込み時はサブフォルダ構造も維持します  
  - 例: `写真/2024/画像テスト.jpg`

### fallback（安全な形式への変換）

ファイル名に使用できない文字（`\ / : * ? " < > |` など）が含まれる場合のみ、次の形式に変換します。

- 例: `image_001.jpg` / `image_002.png`

### 補足

- 古い OS やブラウザでは、日本語ファイル名が正しく表示されない場合があります
- その場合は ZIP 形式でのダウンロードを試してください（UTF-8 対応）

## 変換完了後の画像読み込み

### 変換前

- ファイルやフォルダを **追加読み込み** できます（従来どおり）

### 変換完了後

- 新しいファイルまたはフォルダを読み込もうとすると、**確認ダイアログ** が表示されます

```text
新しい画像を読み込むと、前回の変換結果は削除されます。続行しますか？
```

| 操作 | 動作 |
|------|------|
| **OK** | 前回の画像一覧・変換結果・履歴をクリアし、新しい画像だけを読み込む |
| **キャンセル** | 何も変更せず、前回の結果を維持する |

読み込み成功時のメッセージ例:

```text
前回の変換結果をクリアして、新しい画像を 12 枚読み込みました。
```

### 変換中

- ファイル・フォルダの追加読み込みはできません（従来どおり）

## スマホ利用時の注意点

Image Convert Lite はスマートフォンのブラウザでも動作しますが、以下に注意してください。

| 項目 | 注意点 |
|------|--------|
| メモリ | 大量・高解像度の画像はメモリ不足で固まる可能性があります。枚数を減らすか、横幅リサイズを設定してください |
| 読み込み上限 | PC と同じく500枚・25MB/ファイルの上限があります |
| フォルダ選択 | スマホのブラウザではフォルダ一括選択が使えない場合があります |
| 変換速度 | 端末性能により PC より時間がかかることがあります |
| ダウンロード | 変換後の ZIP ダウンロードは、ブラウザや OS によって保存先が異なります |
| 推奨 | 大量変換は PC の Chrome / Edge での利用を推奨します |
